## 4. 逐元件規格

### 4.1 PixelMotion

**用途**：讓逐格像素圖的部件依事件或固定節奏換整數格姿勢，靜止時不讓畫面排下一幀。
**內容角色**：`event` 為動作（點擊或按鍵觸發一段動作）；`ambient` 為裝飾圖像。
**何時不用**：要平滑、非整數位移的動畫（用 Flutter 的 `AnimatedBuilder` 或隱式動畫）；要連續表達進度或數值的視覺（進度條）。
**層級**：L2

#### 變體

| 變體 | 外觀差異 | 行為差異 | 何時選用 |
|------|---------|---------|---------|
| `event` | 平常顯示基準姿勢 | 事件觸發一段動作，結束後回到靜止、取消計時器；可聚焦、可點擊 | 回饋一個事件（答對、點擊、資料更新） |
| `ambient` | 一直在換姿勢 | 以固定姿勢間隔持續換姿勢，只在姿勢改變時重畫；不可聚焦、不可點擊 | 背景裝飾，且產品確定要一直動 |

#### 狀態矩陣

| 狀態 | 顯示 | 可用操作 | 進入條件 | 退出路徑 | 來源 | 同步策略 |
|------|------|---------|---------|---------|------|---------|
| idle（`event`） | 基準姿勢（全部位移為 0）；不排下一幀、沒有計時器 | 點擊、Enter、空白鍵或 `controller.trigger()` → moving | 掛載；moving 的結束條件成立 | 事件 → moving；卸載 | 互動瞬態 | 本地即時 |
| moving（`event`） | 每個姿勢間隔換一次整數格姿勢，只在姿勢改變時重畫 | 再次觸發：動作從頭起算 | idle 時收到事件 | 姿勢函數回報動作結束 → idle（位移歸 0）；卸載 | 互動瞬態 | 本地即時 |
| focused（`event`） | 同 idle 或 moving，外加焦點環 | Enter、空白鍵觸發 | Tab 移入或點擊 | Tab 移出、點擊別處 | 互動瞬態 | 本地即時 |
| moving（`ambient`） | 同上，持續不停 | 無 | 掛載，且所在子樹的 `TickerMode` 為啟用 | `TickerMode` 關閉 → paused；卸載 | 互動瞬態 | 本地即時 |
| paused（`ambient`） | 停在最後一個姿勢；不排下一幀、沒有計時器 | 無 | `TickerMode` 關閉（被別的路由蓋住） | `TickerMode` 開啟 → moving；卸載 | 資料態：`TickerMode.valuesOf(context).enabled` | 本地即時 |
| reduced | 只顯示基準姿勢；不排下一幀、沒有計時器 | `event`：仍可聚焦、可觸發，觸發時不動作 | `MediaQuery.disableAnimationsOf(context)` 為 true | 設定恢復 → idle（`event`）或 moving（`ambient`） | 資料態：`MediaQuery.disableAnimations` | 本地即時 |

hover、pressed、disabled、loading、error、empty 不成立：游標變形由回饋契約承載、不改變顯示；沒有停用條件；不經服務。

#### 回饋契約

| 事件 | 觸發者 | 反應 | 動畫 token | 時間門檻 | 回饋通道（桌機） | 對應狀態邊 |
|------|--------|------|-----------|---------|-----------------|-----------|
| 可互動提示 affordance | 使用者接近 | `event`：游標變手形；`ambient`：無 | — | 即時 | 游標變手形 | 不適用 |
| 焦點 focus | 使用者／輔助技術 | `event`：焦點環 | — | 即時 | 焦點環 | idle → focused |
| 按下確認 press-ack | 使用者 | 觸發當下套用第一個姿勢；姿勢函數要保證第一個姿勢間隔的位移不全為 0 | `motion.poseInterval` | 100 ms 內 | 部件位移 | idle → moving |
| 定位提示 locate | 系統 | 不可用 + 替代：取得焦點時顯示焦點環；捲動到可見範圍由頁面處理 | — | 即時 | 焦點環 | — |
| 狀態變更提示 state-change | 系統 | 部件位移本身即過渡；reduced 時直接顯示基準姿勢 | `motion.poseInterval` | — | 部件位移 | idle → moving；moving → idle；moving ↔ paused；任一 → reduced |
| 等待與結果 | 系統 | 承載第 1 層（點擊確認）。成功：開始動作。失敗、逾時、服務不可用：不經服務，讀取的場景資料於元件建構時已載入；`scene` 為必填，沒有缺值的情形 | — | — | — | 不適用 |

按下確認的掛載點：元件沒有服務，反應直接由事件觸發。

#### 操作機制

| 形態 | 主要動作 | 任務所需精度 | 該形態輸入精度 | 替代機制 | 回饋通道 |
|------|---------|-------------|---------------|---------|---------|
| 桌機 | `event`：點擊元件任一處；Tab 移焦點後按 Enter 或空白鍵。`ambient`：無 | 命中元件範圍，至少 24 × 24 邏輯點 | 滑鼠指標 1 邏輯點 → 足夠 | 鍵盤（Enter、空白鍵） | 游標變手形、焦點環、部件位移 |

#### 尺寸契約

| 項目 | 值 |
|------|-----|
| 尺寸模式 | 固有尺寸：場景格數 × 每格邏輯點（由 `scene` 提供） |
| 最小尺寸 | 同固有尺寸，不縮放 |
| 最小命中區 | `hitTarget.desktop`；固有尺寸小於它的場景，命中區擴到 24 × 24 |
| 最大尺寸 | 同固有尺寸 |
| 視窗比元件窄時 | 維持固有尺寸，空間不足由所在容器的空間不足策略處理 |
| 裝置像素比 | 支援 1.0 與 2.0：每格邏輯點取整數，乘上整數像素比後每格對齊整數像素。非整數像素比不保證 |

|-----------|---------|---------|---------|-------------|
| 不適用：沒有顯示文字的 slot（朗讀標籤只給輔助技術） | — | — | — | — |

#### slot 契約

| slot | 接受型別 | 必填 | 資料來源 |
|------|---------|------|---------|
| `variant` | `PixelMotionVariant`（`event`／`ambient`） | 是 | 呼叫端 |
| `scene` | `PixelScene`：不會動的背景點陣圖、會動部件的 atlas、每個部件在 atlas 與場景裡的範圍、場景格數、每格邏輯點 | 是 | 呼叫端以 `PixelScene.build` 產生。輸入：背景與每個部件各一張錄好的 `Picture`（座標單位是格）與部件的格子範圍。`build` 把背景與部件畫成 1 格 = 1 px 的點陣圖，部件拼成 atlas，部件之間留 1 px。運動參數不在這裡，由 `motion` 提供 |
| `motion` | `PixelPose Function(Duration elapsed)`：輸入動作開始後的經過時間，輸出每個部件的整數格位移，以及動作是否結束（`ambient` 不看） | 是 | 呼叫端 |
| `controller` | `PixelMotionController?`（`event` 才有作用） | 否；不給時只能點擊或按鍵觸發 | 呼叫端 |
| `semanticLabel` | `String`（呼叫端從 i18n 取值） | `event` 必填；`ambient` 不填時元件從無障礙樹排除 | 呼叫端 |

**時間來源**：`elapsed` 由元件依觸發後經過的姿勢間隔數累計（第 n 次為 n × `motion.poseInterval`），不讀真實時間，widget test 推進假時間就能驗證回到靜止。`event` 觸發的當下就以 elapsed = 一個姿勢間隔呼叫第一次並套用。

#### 使用 design token

| 面向 | token |
|------|-------|
| 色彩 | `color.focus`（焦點環）。像素顏色是場景內容，由 `scene` 帶進來，不是 token |
| 間距 | 不適用 |
| 字體 | 不適用 |
| 圓角 | 不適用 |
| 動畫 | `motion.poseInterval` = 100 ms |
| 命中區 | `hitTarget.desktop` = 24 × 24 |

三個 token 由 `PixelMotionTheme`（`ThemeExtension`）提供預設值，app 用 `ThemeData.extensions` 覆寫。

| 項目 | 值 |
|------|-----|

#### 無障礙

| 面向 | 要求 |
|------|------|
| 朗讀標籤 | `event`：`semanticLabel`，角色為按鈕；`ambient`：不填 `semanticLabel` 時從無障礙樹排除，填了時以圖片角色朗讀。文字方向取祖先的 `Directionality`，沒有時以由左到右處理 |
| 狀態變化播報 | 不播報：idle、moving、focused 是互動瞬態；paused、reduced 是資料態，但 paused 時元件看不見，reduced 是使用者自己的設定 |
| 非視覺替代訊號 | `event` 用來回饋事件時，動作不是唯一訊號：呼叫端要另外提供文字或播報 |
| 焦點順序與操作路徑（桌機） | `event`：依版面順序在 Tab 順序中，Enter 或空白鍵觸發；`ambient`：不在 Tab 順序中 |
| 對比 | 焦點環與背景的對比至少 3:1（WCAG 2.2 的 1.4.11 Non-text Contrast） |
| 減少動態 | 見狀態矩陣 reduced 列 |

#### 測試點（widget test）

- [x] `event` 觸發後跑完回到靜止：計時器取消、位移為 0、每一幀畫完之後不排下一幀
- [x] 一支測試逐一渲染兩個變體與全部狀態
- [x] 祖先沒有 `Directionality` 也能掛載
- [x] 觸發的當下就套用第一個姿勢
- [x] `ambient` 在 `TickerMode` 關閉時取消計時器、不排下一幀、停在最後一個姿勢，開啟後恢復
- [x] reduced：只顯示基準姿勢、不排下一幀，觸發也不動作
- [x] `event`：Tab 取得焦點、Enter 與空白鍵觸發、游標為手形、朗讀標籤與按鈕角色
- [x] 固有尺寸小於最小命中區時，元件尺寸擴到 `hitTarget.desktop`
- [x] 裝置像素比 1.0 與 2.0 下，atlas 畫法與逐部件重播 `Picture` 的畫面逐位元組相同
- [x] 覆寫 `motion.poseInterval` 之後計時間隔跟著改變

「靜止時不排下一幀」以 `SchedulerBinding.hasScheduledFrame` 判斷：每一幀畫完之後它是 false，代表沒有排下一幀。

#### 反例

| 不該拿它做什麼 | 應改用 |
|---------------|--------|
| 平滑、非整數位移的動畫 | Flutter 的 `AnimatedBuilder` 或隱式動畫 |
| 用 `Ticker` 每個 vsync 檢查、間隔到了才換姿勢 | 本元件：姿勢一樣，但畫面不會每一幀都排下一幀 |
| 連續表達進度或數值 | 進度條 |
| 當成事件回饋的唯一訊號 | 另外搭配文字或播報 |
